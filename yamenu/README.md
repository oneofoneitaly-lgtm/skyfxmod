# YA MENU by @Adryh01

Separate Forge 1.8.9 mod (independent from YA MODS). It restyles the Minecraft title screen,
Singleplayer and Multiplayer in the same white/grey look as the YA MODS menus, with the YA CLIENT logo.

Install: put `YAMenu-*.jar` in `mods`. Esc goes back. Double-click a world / server to play / join.
Build: see the GitHub Actions workflow (artifact `YAMenu`).
